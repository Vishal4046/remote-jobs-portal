# Remote Jobs Portal

A full-stack web application that connects job seekers with recruiters for remote job opportunities. The project includes job browsing, applications, bookmarks, authentication, and recruiter-side job posting features.

## Project Overview

Remote Jobs Portal is designed to make the job search process easier for candidates looking for remote work. Recruiters can post job openings, and job seekers can search, filter, save, and apply for jobs from one platform.

## Key Features

- User registration and login
- JWT-based authentication
- Job listing and job search
- Job application flow
- Bookmark or save jobs
- Recruiter job posting
- REST API integration
- MongoDB database storage
- Frontend and backend separation

## Tech Stack

**Frontend:** React.js, Vite, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB Atlas  
**Authentication:** JWT  
**Deployment:** Netlify, Railway

## Local Setup

### Backend

```bash
cd backend
npm install
npm start
```

Create a `.env` file inside the backend folder with your database connection, JWT value, and port.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Create a `.env` file inside the frontend folder with your backend API base URL.
